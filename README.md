### CNN For Image Prediction

This is a Convolutional Neural Network that its been used to predict whether the animal in the picture is a dog or a cat. 
First we take the **training** and the **testing** set wich are photos of dogs and cats and we convered the size of the 
pictures to be the same size, more spesific (64, 64) so the model don't get confused with different data size. Note that
you can change the scale to be bigger for better predictions but at the same time it takes more time on the training!
